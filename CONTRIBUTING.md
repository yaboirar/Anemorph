# Contributing

Thanks for helping improve Anemorph!

For a bug report, include your Windows version, Anemorph version, what you expected, and what happened. A few invented example filenames are usually enough; please do not upload videos, personal folder paths, or private settings/history files.

For code changes, keep the change focused and explain the user-visible behavior. Test renaming with disposable copies or generated fixtures. Run `cargo fmt --check`, `cargo clippy --locked -- -D warnings`, and `cargo test --locked` before submitting a pull request.

For interface changes, include before/after screenshots at normal and minimum window sizes. Preserve keyboard selection, native dragging, and idle repaint behavior.

Contributions to Anemorph's code are submitted under its MIT license. Do not add assets without clear redistribution terms; see THIRD_PARTY_NOTICES.md.
